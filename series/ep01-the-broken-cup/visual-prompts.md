# Visual Prompts — EP01: The Broken Cup

One ready-to-paste image-generation prompt per row of `shot-list.md` — same numbering, same order, same scene keys — so this file can be worked straight down the page. **20 prompts for 20 key frames**, the collapsed budget published in `script.md` and carried through `storyboard.md` and `shot-list.md`. The three slow push-ins (shots 4, 8, 20) are scale-ups of frames that already exist and are **not** generated again, so there are 20 prompts and not 23.

---

## 1. How to use this file

1. **Generate the location plates once, then reuse them.** Build the fix-it-stand plate and its working areas one time, save those images, and reuse them under every shot below — and in every later episode. Never let an image tool invent the stand again shot by shot; that is where backgrounds drift.
2. **Never regenerate a character's look from scratch.** Every prompt featuring Maya or Gramps Lou carries that character's **locked visual-prompt paragraph, copied verbatim** from `/characters/hero.md` or `/characters/adult.md`. Copy the paragraph, then change the pose and the action only — never the hair, the outfit, the freckles, the untied shoe, the cap, the beard, or the apron.
3. **The locked paragraphs in this file are copies, not the source.** Do not edit them here — not a word, not a comma, not a hyphen. If a locked look ever has to change, change it in `/characters/hero.md` or `/characters/adult.md` and re-copy it down into this file. Never the other way around.
4. **Each prompt is self-contained.** An image tool sees only the one prompt it is given, so every block below restates the plate, the working area, the camera, the light, and the continuity state. Paste one block, generate one frame.
5. **The locked paragraph describes the design, not the mood of the frame.** It says "gap-tooth smile" because that is her face, not because she is smiling in that shot. The per-shot **EXPRESSION** line is what the frame plays and it governs. Maya does not smile once between shot 1 and shot 16; the locked gap-tooth grin lands in shot 20.
6. **Camera is static wide or slow push-in. Nothing else exists in this show.** No close-ups, no cut-ins, no overheads, no handheld, no fast cutting. Where a small detail has to read — the dust ring, the two pencil dots, the drill, the wrong bolts, the seams — it is drawn big enough to read inside the wide.
7. **No incidental people, ever.** The plate is built empty and stays empty: no customer, no passer-by, no neighbor in the background. Maya was the only one in the room, and every frame has to keep saying so.
8. **No on-screen text in any generated frame.** No signage, no lettering on the mug, no logo, no captions. The only text in the episode is the end card, built in the edit off shot 20.

**Plates are built ONCE and reused across ALL episodes — they are not regenerated per episode, and not per shot.** Generate the master build below, save it, then generate the three area framings off that same build and save those too.
