# Production SOP — One-Person Pipeline

story → script → locked character frames → key shots → voice → edit → captions → thumbnail → upload → Shorts cut

Built for: one person, not on camera, using AI assistance at each step, repeatable enough that episode 12 still looks like episode 1.

## Tool stack (max 6 — here's where it stands today)
| Step | Tool | Status |
|---|---|---|
| Scripting, planning, visual-prompt writing, timeline generation | Claude Code | **Have** |
| Character frames / key shots / location plates | Google Gemini image models ("Nano Banana"), via AI Studio or the API | **Picked** |
| Voice | ElevenLabs, used as **speech-to-speech** — performed into a mic, then converted | **Picked** |
| Edit + captions | Shotcut, version-frozen, `.mlt` timeline generated by Claude Code | **Picked** |
| Thumbnails | Same image tool as character frames | **Picked** (covered above) |
| Upload / scheduling | YouTube Studio directly | Available whenever |

Four of six slots used, ~$25–35/month all-in. **The full reasoning, verified costs, risks, fallbacks and the pre-flight test for each pick are in TOOL-DECISIONS.md** — read it before spending anything, including the note on how solid the pricing actually is.

Three things from that file are easy to lose and expensive to rediscover:

- **Voice is speech-to-speech, not text-to-speech.** You perform every line of both characters; Maya's performance is converted to a locked child voice. Typing lines into a TTS box will not produce this script — the consistency setting and the expressiveness setting are the same dial turned opposite ways, and the whole show is directional performance notes.
- **Every image branches from the frozen master character sheet, never from the previous frame.** Identity drifts after roughly 8–10 sequential edits. Chain edit-on-edit down a 20-frame episode and episode 12 will not match episode 1.
- **The editor is chosen because its project file can be written by a program.** Placing ~121 audio stems per episode by hand, 40 times, is the actual weekly job and the actual source of drift. If you won't build the `.mlt` generator, switch to DaVinci Resolve free and accept hand-assembly.

CapCut was considered and rejected on its terms, not its features — see TOOL-DECISIONS.md.

## Constraints
- Not on camera, ever.
- Character sheets in `/characters/` must be locked before any episode is produced — episode 12 needs to look like it's from the same show as episode 1.
- Fewer shots, held longer, beats chaotic cutting. 12–20 key frames per episode (see EPISODE-ENGINE.md).
- If a week goes badly: the "tiny episode" path below, not a skipped week.

## The tiny-episode fallback
If 15+ hrs isn't available in a given week: cut to a 3-minute story, same formula (hook → problem → failed try → new try → skill named → practice), 6–8 key frames instead of 12–20, one location. Better to ship something small on schedule than to break the weekly habit — the habit is what the audience (and the algorithm) actually rewards.

## Character sheets
`/characters/hero.md`, `friend.md`, `sibling-or-cousin.md`, `adult.md` — each with name, age, a look that never changes (hair, colors, outfit), personality, a do/don't list, and one locked visual-prompt paragraph to copy into every image generation for that character.

## Production board
`/trackers/production-board.csv` tracks each episode through: script → voice → frames → edit → live, with an owner, a due date, and a blocker field. Filled with the first 30 days in 90-DAY-PLAN.md's schedule.
